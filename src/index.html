How it works

  1. 01

    Connect

    MetaMask (or any injected wallet) signs transactions. Without a wallet the page runs in demo mode, simulating the contract in your browser.

  2. 02

    Claim

    Clicking Claim calls adopt(avatarId) on the Adoption contract, which stores msg.sender as the owner — and reverts if the avatar is already taken.

  3. 03

    Verify

    The UI reads getAdopters() — a fixed array of 16 addresses — to show who owns what, straight from the chain.

View the smart contract 
// SPDX-License-Identifier: MIT
contract Adoption {
  uint public constant SUPPLY = 16;
  address[16] public adopters;

  event Adopted(uint indexed avatarId, address indexed owner);

  function adopt(uint avatarId) public returns (uint) {
    require(avatarId < SUPPLY, "Invalid avatar id");
    require(adopters[avatarId] == address(0), "Avatar already claimed");
    adopters[avatarId] = msg.sender;
    emit Adopted(avatarId, msg.sender);
    return avatarId;
  }

  function getAdopters() public view returns (address[16] memory) {
    return adopters;
  }
}
